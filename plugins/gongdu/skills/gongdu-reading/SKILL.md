# 共读

使用本插件附带的 `gongdu` MCP 工具。它运行于用户本机，由已有共读项目启动；不用另建服务器或索取模型密钥。迁移期间可能仍有旧的 `pdf_reader` 连接，优先使用本插件的 `gongdu` 工具。

- 用户说“打开共读书库”时调用 `open_library`，让用户在阅读器中选择资料。不要仅返回文件路径或说明。
- 按路径打开 PDF 时先核对已授权文件，再调用 `display_pdf`；不要扩大目录权限或扫描磁盘。
- 用户提到“这一段”“选中的内容”时，优先使用阅读器提供的上下文；缺失时读取当前阅读器状态，确认资料、版本、页码或行号和实际选区。不要把上一次选区当成当前选区。
- 解释时区分原文、用户自己的理解和 AI 推断，保留可回到原文的位置。OCR 引文须说明未经人工核对。
- 学习时一次问一个关键问题，先听用户的解释或预测，再补充纠正；不把阅读页数、生成笔记或工具调用本身视为掌握知识。
- 用户请求保存、导出或删除笔记时，使用阅读器现有功能；仅在用户要求保存到其他位置时使用对应工具。不要自动创建空间、上传原件或改写用户判断。

如果本机连接尚未加载，说明需要刷新插件连接或重新打开客户端；不能把配置存在当成工具已连通。项目移动或依赖缺失时，从正式维护目录重新执行 `scripts/install-plugin.ps1`，不要手工修改插件缓存。
